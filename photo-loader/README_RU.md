# PUDRA PHOTO LOADER — автономный загрузчик фото

Отдельный фоновый модуль в GitHub Actions для FAMILYTURCOMPANY / Provecta. Не зависит от TinyFish и не меняет работу PUDRA STOCK.

## Как работает

- Каждые два часа GitHub запускает Node.js + Chromium (Playwright), даже если ChatGPT закрыт.
- Через рабочие данные Provecta API читает каталог товаров, отсеивает удалённые позиции, пропускает товары с уже имеющейся фотографией.
- Ищет по штрихкоду и названию публичные страницы товаров. Для загрузки требует точный штрихкод на найденной странице и соответствие нескольким словам названия.
- Из проверенной страницы берёт оригинальное OG-изображение, проверяет тип и размер файла; если нет надёжного совпадения — пропускает.
- Открывает карточку товара в Provecta, раздел Images → Upload → Paste link here → Apply → Save, затем сразу переходит к следующей, не открывая уже сохранённую карточку повторно.
- Хранит курсор, статусы и отчёт о последнем запуске в GitHub Actions Cache. Если кэш сброшен, старые фото повторно не добавляются: перед загрузкой проверяется галерея.
- Не изменяет цены, остатки, наименования и штрихкоды.

## Однократная настройка (обязательна)

На GitHub: Settings → Secrets and variables → Actions → New repository secret

1. PROVECTA_USERNAME — логин кабинета Provecta; не записывать в код.
2. PROVECTA_PASSWORD — пароль кабинета Provecta; не записывать в код.
3. PROVECTA_CLIENT_ID — необязательный ID клиента (если при входе несколько организаций).

До появления первых двух секретов задание не изменяет товары. Не присылайте пароль в чат.

## Запуск / результаты

- GitHub → Actions → PUDRA PHOTO LOADER → Run workflow (или дождаться планового запуска).
- Результат: лог в Actions с кодом товара, штрихкодом, статусом и ссылкой-источником. Статус saved означает, что через UI была нажата кнопка Save без обнаруженной ошибки; повторное открытие карточки не выполняется по требованию пользователя.
- До массовой работы проверьте несколько успешных и пропущенных позиций.

## Лимиты и безопасность

- По умолчанию обрабатывает не более 3 товаров за запуск и только 1 фото на товар.
- URL всегда HTTPS, изображения проверяются по размеру и типу; не используются похожие изображения без точного штрихкода.
- Источники с ограничением индексации, недоступными фото, неоднозначным названием пропускаются, а не подменяются.
- Поисковики и сайт Provecta могут менять HTML/UI. При изменениях загрузка может остановиться; мониторинг GitHub Actions обязателен.
- GitHub Actions и поиск могут иметь лимиты. Это не гарантия постоянной работы или конкретной производительности до реального успешного запуска.
- Для проверки без изменений: вручную запустить локально с PHOTO_LIVE=false.
- Секреты не сохраняются в git, логах или state.json.

## Локальная разработка

Node.js 22, cd photo-loader && npm install && npx playwright install chromium && npm test.
Для реальной работы задать PROVECTA_USERNAME и PROVECTA_PASSWORD в окружении и запустить node loader.mjs.
